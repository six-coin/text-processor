# 文本处理器 使用手册

用一个个小 Python 脚本，把长文档处理成一条可回看的版本链。

[English](en-US.md)

---

## 1. 安装

需要 Windows 10/11、[uv](https://docs.astral.sh/uv/)、WebView2 Runtime（Windows 11 自带；Windows 10 一般随 Edge 装好了）。

```bat
setup.bat
```

它执行 `uv sync`，把依赖装进程序目录下的 `.venv`。换机器时把整个目录拷过去，重新跑一次 `setup.bat` 即可。

## 2. 启动

| 文件 | 用途 |
|---|---|
| `main.bat` | 日常启动，不弹控制台窗口 |
| `main.pyw` | 同上，直接双击也可以 |

程序只允许开一个窗口。再次启动时不会开新窗口，而是把已经打开的那个提到前面。

## 3. 界面

窗口分三栏：

| 区域 | 放什么 |
|---|---|
| 左栏 | 项目列表与搜索框，底部是「新建项目」 |
| 中栏 | 当前版本的正文，只读；顶部一行是标题、版本号、时间、字数与工具按钮 |
| 右栏 | 「操作」「历史」两个页签，底部进入处理器页 |

窗口窄于 1120 像素时，右栏收成抽屉，点中栏右上角的三道杠展开。

## 4. 项目

- **新建**：点左下「新建项目」，或按 `Ctrl+N`。填名称，把文本粘进「初始文本」，也可以点「从 txt 导入」直接选文件。
- **导入**：认得 UTF-8、GBK/GB18030、带 BOM 的 UTF-16；文件大小没有额外限制。
- **搜索**：左栏顶部按名称过滤，不区分大小写。
- **删除**：鼠标移到项目行，点右侧出现的垃圾桶图标。项目会移进回收站，不会立刻消失。

## 5. 版本

每一次处理都会生成一个新版本，旧版本原样保留。

| 操作 | 结果 |
|---|---|
| 运行处理器 | 追加一版，标题是处理器名 |
| 手动修改 | 追加一版，标题是「手动修改」 |
| 点「历史」里的某一版 | 正文切到只读预览，顶部出现一条提示 |
| 「从此版本继续」 | 删掉这一版之后的所有版本，回到这一版 |

「从此版本继续」会真的删除后面的版本，确认框里写明丢几个、无法撤销。预览状态下不能运行处理器，也不能手动修改。

## 6. 处理器

处理器是「把文本变成新文本」的小脚本。内置五个：去除首尾空白、移除空行、查找替换、检查行末标点、检查行长度。

运行：右栏「操作」里点一个，填参数，确认。

| 类型 | 做什么 |
|---|---|
| 行处理 | 逐行处理，行数不变 |
| 全文处理 | 拿到整篇文本，可以增删行 |
| 检查 | 不改文本，只列出需要注意的行并给出原因 |

行处理器可以打开「逐行确认改动」：改动会先列成一张表，每行一个开关，由你决定哪几行生效。

## 7. 手动修改

中栏右上角「手动修改」打开一个编辑器。

| 按钮 | 作用 |
|---|---|
| 保存 | 生成一个新版本 |
| 在外部编辑器中打开 | 把当前内容写到临时文件，用系统默认程序打开；之后这里的文本锁定为只读 |
| 重新读取 | 把外部编辑器保存后的内容读回来 |

在外部编辑器里改完直接点「保存」也可以——保存前会自动读一次磁盘，不需要先点「重新读取」。

## 8. 用 AI 写处理器

处理器页 →「用 AI 写」：

1. 用一句中文说清你要的效果。
2. 点「复制提示词」，整段提示词（含接口说明与三段示例）进剪贴板。
3. 粘给任意网页端 AI，拿到它返回的代码。
4. 把代码粘回第二步的框里，点「校验并保存」。

校验不通过不会保存，错误信息会指出行号。提示词里已经写全了接口约定，AI 不需要看到本程序的代码。

## 9. 处理器页

左栏按类型列出所有处理器，内置的带「内置」标记。右栏是源码编辑器。

| 按钮 | 作用 |
|---|---|
| 检查 | 只校验，不保存 |
| 保存 | 校验通过后写入；不通过会指出原因 |
| 删除 | 删掉这个处理器；已经用它生成过的版本不受影响 |

内置处理器只读：代码不能改，也没有删除按钮。想改内置逻辑，用「手写代码」或「用 AI 写」新建一个。

## 10. 查找

`Ctrl+F` 打开查找条。输入即高亮，回车跳到下一处，`Shift+Enter` 上一处。查找只覆盖当前显示出来的内容。

## 11. 快捷键

| 按键 | 作用 |
|---|---|
| `Ctrl+N` | 新建项目 |
| `Ctrl+F` | 打开查找 |
| `Esc` | 关闭查找条或弹窗 |
| `Enter` | 查找条里跳到下一处 |
| `Shift+Enter` | 查找条里跳到上一处 |
| `Ctrl+S` | 处理器编辑器里保存 |

## 12. 设置

点左上角齿轮。设置存在 `app.json` 里，改完立即生效。

| 设置项 | 取值 | 说明 |
|---|---|---|
| 界面语言 | 简体中文 / English | 立即切换，下次启动沿用 |
| 主题 | 浅色 / 深色 | 立即生效 |
| 自动换行 | 开 / 关 | 关掉后正文不折行，左侧显示行号 |
| 正文字体 | 微软雅黑 / 宋体 / 黑体 / 楷体 / 仿宋 / 等线 | 只影响预览 |
| 正文字号 | 13 / 14.5 / 16 / 18 / 20 | 只影响预览 |
| 正文显示上限 | 5,000 / 10,000 / 20,000 / 50,000 / 不限制 | 超出部分不显示；处理仍按全文算 |
| 日志级别 | 调试 / 常规 / 警告 / 错误 | 改完立刻生效，日志仍写在同一个文件里 |
| 自动清空日志 | 开 / 关 | 启动时删掉超过保留期的日志文件；关掉就一直留着 |
| 日志保留天数 | 1–365 | 默认 30；关掉上面的开关时这一项不起作用 |
| 数据目录 | 任意绝对路径 | 改完下次启动搬迁，可立即重启 |
| 回收站 | — | 打开被删项目所在的目录 |

## 13. 文件与目录

```
<程序目录>                    代码与随程序分发的资源
<数据目录>                    %PROGRAMDATA%\six-coin\text-processor
├─ app.json                   设置
├─ projects\                  每个项目一个文件夹
│  └─ <项目>\
│     ├─ project.json         版本清单
│     └─ versions\            0001.txt、0002.txt……
├─ processors\                处理器脚本
└─ recycle\                   删除的项目
<本地目录>                    %LOCALAPPDATA%\six-coin\text-processor
└─ logs\                      日志，每次启动一个文件，默认保留 30 天
<临时目录>                    %TEMP%\six-coin\text-processor
```

- `projects`、`processors`、`app.json` 不进版本库。
- 删掉 `<数据目录>` 等于恢复出厂：所有项目与自定义处理器都没了。
- 日志单个文件超过 5 MB 会轮转。默认只留最近 30 天：更早的日志在启动时删掉，可以在设置里关掉自动清空或改天数。

## 14. 常见问题

**双击 `main.bat` 一闪而过。** 没装依赖。先跑 `setup.bat`，它会告诉你缺什么。

**提示「程序已经在运行」。** 只允许一个窗口。任务栏里找一下已经打开的那个。

**正文只显示了一部分。** 「正文显示上限」在起作用。它只影响显示，处理仍按全文算；要全部显示就设成「不限制」。

**改了数据目录，重启后数据没搬。** 搬迁只在启动时做一次。目标目录不可写时不会搬，旧数据留在原处，日志里有记录。

**处理器保存不了。** 看错误信息：多半是 `init()` 少字段，或者 `process()` 的形参和 `args` 对不上。

**处理器运行报错。** 错误信息带行号。先用「检查」定位语法问题，再逐行确认。

## 15. 已知限制

- 只支持 Windows。
- 正文是只读的，所有改动都必须落成一个版本，不能边看边改。
- 处理器在进程内执行，没有沙箱；只挡住了导入网络、子进程、文件写入这几类。
- 查找只覆盖当前显示的内容，受「正文显示上限」影响。
- 没有导出功能，需要时从数据目录直接取 `versions\NNNN.txt`。
- 一次只能开一个窗口、一个项目。
